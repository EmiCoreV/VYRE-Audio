Target Curve

About target curves
Built-in and custom target curves are calculated directly by VYRE Audio. The Native Engine uses the selected curve without querying an external application. B&K and X-curve are practical approximations, not official manufacturer calibration files.
Native correction targets a neutral flat reference unless another curve is selected.

Microphone Calibration

About microphone calibration
audy2umic applies the supplied frequency-response correction to the imported speaker measurements before optimization. Custom accepts a two-column text/CSV file: frequency (Hz), correction (dB). The Native Engine applies the selected microphone correction curve directly to the ADY-derived frequency response.
No microphone correction will be applied.

Customizations

Room-Mode Correction
Limits the maximum additional reduction of detected room resonances. The frequency sliders limit the center frequencies of detected modes. Narrow filter edges may extend slightly beyond the limit.
60 Hz Sets the upper frequency limit for the subwoofer's local room-mode correction (30–120 Hz). Default: 60 Hz.
80 Hz Sets the upper frequency limit for local room-mode cuts on regular speaker channels (40–200 Hz). Default: 80 Hz.

VYRE Audio guideQuick workflow
 
1 · Select source and load
Native mode: load an Audyssey MultEQ Editor .ady file with its original impulse responses; REW is not required. Manual REW mode: start REW, enable its API server, import and name your microphone measurements, then load a matching .ady template.
 
2 · Load calibration
Choose the Audyssey MultEQ Editor .ady file for the receiver/setup you want to work with. VYRE reads detected channels, delays, trims and impulse-response data.
 
3 · Choose a target
Select a built-in VYRE target or a custom two-column curve file (frequency in Hz and gain in dB).
 
4 · Microphone correction
Optionally use the built-in audy2umic profile or import a custom two-column correction file. Avoid applying the same correction twice.
 
5 · Calculate
Run the Native Engine. It transforms the ADY impulse responses with an in-browser FFT and calculates correction target curves.
 
6 · Review results
Inspect each source response and requested target. This preview does not predict the receiver's actual post-Audyssey response.
