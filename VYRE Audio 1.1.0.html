Target Curve

About target curves
Built-in and custom curves are generated directly by VYRE Audio and override REW’s active house curve for this optimization. “Use curve currently selected in REW” is the only option that uses REW’s house-curve file. B&K and X-curve are practical approximations, not official manufacturer calibration files.
No target shaping will be applied. VYRE uses a neutral flat reference target.

Microphone Calibration

About microphone calibration
audy2umic applies the supplied frequency-response correction to the imported speaker measurements before optimization. Custom accepts a two-column text/CSV file: frequency (Hz), correction (dB). REW reads the active mic-calibration file configured in REW and applies it to the imported measurements.
No microphone correction will be applied.

Customizations

Room-Mode Correction
Maximum combined attenuation around detected local room-mode peaks. This is a limit, not a fixed amount of attenuation.
60 Hz Sets the upper frequency limit for the subwoofer's local room-mode correction (30–120 Hz). Default: 60 Hz.
80 Hz Sets the upper frequency limit for local room-mode cuts on regular speaker channels (40–200 Hz). Default: 80 Hz.

VYRE Audio guideQuick workflow
1 · Prepare REW
Open REW and enable its API server. In standard mode, VYRE imports the .ady measurements. In manual REW mode, import and sort your own UMIK measurements before loading the .ady template. In REW, open Preferences → Viewand set Maximum measurementsto 1000.
2 · Load calibration
Choose the Audyssey MultEQ Editor .ady file for the receiver/setup you want to work with. VYRE reads detected channels, delays, trims and impulse-response data.
3 · Choose a target
Keep REW's active house curve or select a built-in VYRE target. Custom target files use two columns: frequency in Hz and gain in dB.
4 · Microphone correction
Use REW's current calibration, the built-in audy2umic profile, or import a custom two-column correction file. Avoid applying the same correction twice.
5 · Optimize
Review the options, then start optimization. Keep this page open and do not edit REW measurements while the run is active.
6 · Review results
After completion, inspect each MLP final curve. LFE is normalized over its passband, while speaker curves use the 500–2000 Hz reference band.
Important
Built-in targets are practical listening targets, not certified calibration files. Verify results by listening and checking exported data before applying them.
